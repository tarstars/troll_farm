# D172a — Available observables cannot learn the positive option contexts

**Status:** `closed`  
**Review state:** `proposed`  
**Decision date:** 2026-07-29  
**Scope:** D172a observation class, budget-1 decisions, linear and MLP function classes, frozen LOBO selection blocks.

## Question

Can linear or MLP policies identify the resident-native option envelope’s positive contexts from the 64-field plus affordance observations?

## Decision

No. The signal exists but is not identifiable from the tested observables; selector learning on those features is closed.

## Decisive evidence

- **positive_context_rate**: 40.4% of 27,392 states carry a ≥+2 option  
  Population: 27,392 on-distribution budget-1 states  
  Evidence: `docs/CONSTRAINTS.md` (lines 358-367) [panel_causal]
- **held_value**: +0.14..+0.26 vs +1.5 gate  
  Population: eight held selection blocks across linear and MLP classes  
  Evidence: `docs/CONSTRAINTS.md` (lines 358-367) [panel_causal]
- **admitted_fits**: 0 admitted fits  
  Population: D172a phase-3 evaluated fits  
  Evidence: `data/analysis/live-agent-6553250/d172a-dense-counterfactual-option-policy-phase3-result.json` (/admitted_count) [panel_causal]

## What this does not prove

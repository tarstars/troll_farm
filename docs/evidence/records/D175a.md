# D175a — Bounded early planting is causally harmful on the resident scheduler

**Status:** `closed`  
**Review state:** `proposed`  
**Decision date:** 2026-07-29  
**Scope:** D175a bounded early-plant intervention on the exact resident scheduler and frozen paired panel.

## Question

Does moving the resident’s first planting earlier create a useful production loop without destroying its comparative advantage?

## Decision

No. The mechanism fires, but early planting is severely harmful because it feeds opponents and displaces suppression while failing to improve reaping.

# P-0 — the head-to-head panel instrument: built, tested, validated (2026-09-02)

Plain words first. Track P needs a local judge for the port of norxondor_gorgonax before any
ladder hour: the candidate against the champion of record on the same real maps, once on each
seat, so every map is a paired observation. This is that judge. It reuses the July Python referee
that the bench and the network gates already run on, adds nothing to the rules of the game, and
writes its rows in the shape the frozen gate reader (`gate1.py`) already reads.

## What was built (all under `claude_1/h2h-panel/`)

- **`h2h.py`** — two compiled bots, both seats, paired by map. One new piece: the bench's
  `apply_two` raises when the seat-1 line has a command error (that seat used to be the bench's
  own policy); `apply_pair` parses both lines, counts errors on both, raises on neither. Rows:
  `map_hash`, `policy_seat`, `policy_won`, `policy_score`, `bot_score` and the three fault totals,
  so `gate1.py --treatment 0=A-vs-champion.json --control 0=B-vs-champion.json --expected-cells
  400` reads a paired interval unchanged. The report also carries a head-to-head reading: per
  map the candidate's win indicator and margin averaged over its two seats, then
  `gate1.clustered_bootstrap` over maps (10,000 draws, seed 1) — a map's two seats always travel
  together in a draw.
- **`make_panel.py` → `panel-200-seed1.jsonl`** — 200 distinct maps by a seeded shuffle, start
  inventories drawn as `smoke.py` draws them (2..10 of each fruit and of iron, no wood), sidecar
  and manifest.
- **`bed_new_bot.py`** — the bed for a bot that is not the champion's child.
- **`test_h2h.py`** — 9 tests: the symmetric error counting; both seats' moves execute; the
  mirrored game (orchard 6 on seat 0 vs the champion **is** the champion on seat 1 vs orchard 6:
  scores, turns, ending and trains swap exactly); the champion against itself is the same game on
  both seats; replays keep both lines; the rows load through `gate1.Bench` with no faults; the
  paired reading carries both seats of a map together (a split-seat panel has a zero-width
  interval at one half, the same rows read as independent games do not); the panel draw is
  deterministic by seed and distinct by map; the committed panel matches its sidecar and manifest.
  All pass (47 s, two compilations).

Faults are command errors on the policy's lines / on the bot's lines / turns past five seconds.
The interval is the clustered bootstrap over maps; "win rate" counts strict wins, so a tie is
not a win — read it against the loss count, not against one half.

1. **The champion against itself.** Deterministic identical bots on a mirrored map: 113 wins,
   113 losses, 174 ties (87 maps tie exactly), margin exactly 0.0 on every map — the seat
   plumbing is symmetric. The decided maps split **seat 0: 52 wins, seat 1: 61 wins**: a small
   seat-1 edge on this panel (the referee resolves contested moves and the turn order by unit
   id), which the paired design cancels and which the two-seat rule exists for.
2. **Orchard 6 against the champion: 65–11–324, margin −26 [−30.6, −21.6].** The head-to-head
   says the champion is clearly the stronger bot, on both seats (35 wins on seat 0, 30 on seat
   1). Their ladder readings the same day were 18.8 (orchard 6) and 18.2 (the champion). That is
   the non-transfer the card names — a head-to-head edge over our own lineage need not be an
   edge over the field — and it is why rung 2 (the real Legend agents through the test
   endpoint) sits between this panel and the ladder. Reported as a fact, not a verdict on
   orchard 6.
3. **The old champion (denial on) against the champion (denial off): −0.7 [−1.4, +0.1].** The
   four-line denial rule reads as nothing here — 122–131–147 — where the July bench had read it
   as 0 wins–6 losses and −150 a game. The ladder read the ablation at ±0. This panel agrees
   with the ladder, not with July.
4. **Throughput on the VM (4 cores, `--jobs 4`):** 400 games in 55–70 s without replays
   (26,000–32,000 games an hour), 154 s with every command line kept (10,000 an hour). A full
   rung 1 (400 + 400 games) is under five minutes. The candidate's own turn time will change
   this: the champion runs at about 1 ms a turn.

**A fidelity note the coordinator should have before reading any candidate.** These games are
shorter than ladder games: median 173–186 turns here, 6 % reaching turn 300, against a median of
296 and 46 % reaching 300 in the champion's 160 collected ladder games (`ladder-read.json`), and
mean scores of 116–142 against 183 there. The reason is the referee's end rule, ported from the
game's own: once no plant stands, a grace of a few turns runs and then a stuck player behind ends
the game (mercy) or both stuck end it. Two clear-cutting bots of our lineage exhaust the map by
turn 180; the ladder field plants, so its games run to 300. The port plants (the banana loop is
its signature), so its games here will run longer than these — the numbers above are the
instrument's calibration on our own bots, not the shape of a port game.

## The bed for a new bot (`bed_new_bot.py`)

For a bot that shares no line with the champion, "differs from the champion on k of 34" is not
a build check, so it is reported and not gated. What is gated: plays 34/34 to the end (no empty
command), deterministic on rerun, the compacted file plays exactly as the readable one (MSG
included — the compacted file is what the ladder receives), and the diagnostics line decodes
under the v6 grammar (`narrate6.decode`: one MSG token, first, within budget, every field) on
every turn so `ladder_read.py` can read the collected games. The champion's own v6 invariants
(`kp=0`, `pz=1`, the branch codes) are not enforced: they describe the champion's branches.

Control run — the champion of record on its own bed (readable arm `32172393…`, submission
`0e92f8fa…`): **PASS** — plays 34/34, deterministic 34/34, compacted == readable 34/34,
telemetry errors 0, differs from the champion 0/34 (as it must). A first run against
`readable/denial-off-champion.rs` failed 0/34 on "compacted == readable" with a telemetry error
on every turn: that file is the source of record **without** the diagnostics line, which the v6
arm adds. The port's readable file must carry the MSG line itself (the charter says so); the
bed checks that it does.

## What is asked of codex_1 for the build (so the panel reads it without a change)

- A single `.rs` file that compiles with `rustc --edition=2021 -O`, reads the protocol as
  player 0, writes one command line a turn with the v6 `MSG` token first.
- The readable file with the diagnostics line, compacted by `cgauto/compact_rust_source.py`;
  the bed compares the two in play.
- Nothing else: the panel compiles the file itself and runs both seats.

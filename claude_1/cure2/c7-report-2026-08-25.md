## The counting shape, settled before the run and not after it

The coordinator required it explicitly: *a poison turn with two or more exchanges must count as
**fired**, never as **ambiguous**.*

`swap_loop_control.py` — the published control — pairs `S` movers to `X` partners off the v5 wire.
The wire carries the per-unit branch codes and the count `sw`, but **not which `S` went with which
`X`**. On a turn granting one exchange the pairing is forced; on a turn granting two or more it is
not, and the published control declares the turn AMBIGUOUS and counts it against the gate rather
than guessing. That is the right conservative choice for a candidate whose count is 0, and the
wrong one for a poison: it would print *"ambiguous"* and mean *"fired"*.

So C-7 fixes the shape by changing the **source** of the pairing, not by guessing at one. An
exchange writes exactly two commands. Given the referee's own pre-turn cells, `{a,b}` is an
exchange iff

```
dest(a) == cell(b)   and   dest(b) == cell(a)   with   branch(a),branch(b) == S,X
```

A cell holds one unit, so this is forced no matter how many exchanges a turn granted. Nothing is
guessed and nothing is dropped: a multi-exchange turn contributes **every** one of its pairs.

Three gates keep the new pairing honest — each aborts the run rather than degrading it:

| gate | requirement | result |
|---|---|---|
| **G-P** pairing completeness | on every turn of both arms, command-pairs count `==` the wire's `sw`, and the paired units are exactly the units carrying `S`/`X` | **PASS — 109 600 turns**, both arms |
| **G-B** baseline identity | the unpoisoned arm re-run here reproduces the published `swap-loop-control.json` exchange-for-exchange, and every panel game reproduces its `panel-swap-census.json` count | **PASS** — 20 exchanges on the same 12 pairs and turns; 240/240 panel counts |
| **G-C** wire/command agreement | on every single-exchange turn the two pairings must name the same pair | **PASS** — 66 baseline + 435 poison turns, **0 disagreements** |

G-B is what makes the two arms the same population; G-C is what makes the command pairing a
**strict extension** of the published one rather than a different measurement.

## What the poison deletes, and what it deliberately keeps

Diff against `arm-instrument.rs`: **two hunks, 69 changed lines, all inside the predicate.**

Deleted:

- **P1** — clause 4's `prev_cells` **standing memory**. This is the only cross-turn memory in the
  predicate and the only thing that can refuse an immediate back-swap. Deleting it is precisely
  the poison C-6 exists to catch.
- **P2** — clause 5's adjacency test. A landing two cells away now exchanges.
- **P3** — clause 6, **both** halves: the teammate-on-goal skip and the strictly-beyond BFS test.

Retained, and stated so the poison is not over-read:

- **R1** — `!moving_ids` / `!displaced`. Both are per-pass locals with no memory across turns, so
  neither can suppress the **next** turn's back-swap, which is what C-5/C-6 count. Without them a
  single pass can rewrite one unit's command twice, and the run would measure a **malformed
  command stream** instead of a loop — G-P would abort rather than report a fire.
- **R2** — the positional slot map. It is the mechanism that writes the partner's command, not a
  test of whether to exchange.

## Limits, stated as limits

- **The ambiguity the shape was built for never occurred.** `max_exchanges_on_one_turn` is **1** on
  **both** arms over all 274 games — even with the predicate gutted. So the run does not demonstrate
  that the pairing survives ambiguity: there was no ambiguity to survive. `test_c7_pairing.py`
  fabricates the withheld turn and tests it at the function level (**8 tests OK**), including the
  case where the natural ascending-order guess picks the **wrong** pairs. The honest claim is
  *"tested at the function level, never observed in the corpus"*, not *"tested by the run"*.
- **Consequently the published wire pairing would also have caught this poison** (`wire_pairing`
  reports 0 ambiguous turns and a FAIL verdict on the poison arm). The command pairing is the
  stronger instrument; on this corpus it was not the *necessary* one.
- **C-7 does not show the candidate's C-5 = 5 is benign.** It measures only that the counters can
  count. The pre-committed STOP AND ASK on those five repeats stands and is the owner's ruling.
- **37 / 36 incidental position exchanges** (two planners crossing with no `S`/`X` codes) are
  reported and **not** counted as rule exchanges; counting them would credit C-5/C-6 with swaps the
  predicate never granted.
- The poison is one shape of "gutted". A predicate broken some other way is not covered.

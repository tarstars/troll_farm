# The P3 read on the candidate arm — the bar is met, and 228 of the 240 zeroes are a guard returning early

Task `20260825-dance-cure-candidate-2-swap`. Subject `claude_1/cure2/arm-candidate.rs`
(`sha256 5577cdce4789…`, `NARRATE_V5_ENABLED=false`). Runner
`claude_1/cure2/p3_read.py`. Result `claude_1/cure2/results/p3-read-candidate-arm.json`.
Grading is `fuzz_panel.eval_p3` **imported** (`claude_1/pipeline/fuzz_panel.py:1817`), not restated.
Re-run byte-identical.

## Why this run exists

C-16 answered the **red** half of R-B: flip `SWAP_P3_SCOPING_ENABLED` to false and 9 of 60
orchard-eligible seat views produce a P3 violation. That establishes the scoping is doing work. It
establishes nothing about the arm that would be submitted, because on the eligible class the scoped
arm is byte-identical to the parent *by construction*. G-0 §8 carries the bar

> P3 games on orchard-eligible views (whole-game) | **0**

and against that bar the candidate arm's number was **UNMEASURED — not passed**. This reads it over
the whole 240-view panel population.

## The number, and the decomposition that is the actual read

| quantity | value |
|---|---|
| seat views graded | 240 (12 orchard-eligible, 228 not) |
| **P3 violations, `fuzz_panel.eval_p3`** | **0** |
| bar met | yes |

A bare 0 does not distinguish "the property was checked and held" from "the property was never
reachable". `eval_p3` has exactly three exits, and every view is classified by which one it took:

| `eval_p3` exit | views |
|---|---|
| **A** — `not orchard_eligible`: the guard returns `[]` before the streams are compared at all | **228** |
| **B** — eligible, streams compared and **equal** (the scoping's whole-game inertness) | **12** |
| **C** — a violation | **0** |

So the bar is met, and **no part of the zero comes from the candidate changing a stream and P3
finding it acceptable.** 95 % of it is a guard; the other 5 % is inertness the design puts there on
purpose and states as a cost in §3.6.

**Exit C is reachable on this exact population.** On these same 12 eligible views the scoping-off
arm fires P3 once (`m004:0`, `results/c16-scoping-control-primary.json`). The zero is not a dead
branch — it is a live branch that did not fire.

## P3\* — the counterfactual, published as a size and never as a verdict

`eval_p3(True, candidate, parent)` applied to the **non-eligible** views: the same whole-stream
predicate where P3 by definition does not reach. This is **not** a property violation and is never
reported as one.

| quantity | value |
|---|---|
| non-eligible views | 228 |
| views whose stream the candidate changes | **28** |
| first divergence turns | 2, 3, 3, 3, 4, 4, 6, 6, 7, 7, 8, 8, 12, 12, 12, 18, 19, 21, 28, 29, 51, 53, 61, 76, 79, 81, 177, 194 |

Those 28 are **exactly** the 28 games the C-4/C-15 census recorded an exchange on — a different arm
(the instrument arm) read by a different route (its `sw=` wire). That is gate G-C.

## A figure that changes meaning at a boundary — both aggregates, named

C-15's published net cost is a delta of **own scores**. The C-16 and P3\* figures are deltas of
**margin** (own score − opponent score). Over this panel they differ **in sign**:

| aggregate over 240 views | value |
|---|---|
| own score, candidate − parent | **−24** |
| opponent score, candidate − parent | **−80** |
| **margin, candidate − parent** | **+56** |

The candidate banks 24 fewer of its own and holds the opponent 80 lower. Both numbers are real;
neither may be quoted as the other. C-16's "+39 forgone margin" is a margin figure and is
consistent with this. This belongs in the G-1 cost table with the units written out.

## Gates — each aborts the run rather than degrading the number

| gate | result |
|---|---|
| **G-S** subject identity | PASS — hash matches `cure2-candidate-config.json` and the sidecar; declares `NARRATE_V5_ENABLED=false`; differs from `arm-instrument.rs` in exactly that one line |
| **G-Q** narration observed off | PASS — on all 240 views the candidate's `MSG` fragments are identical to the parent's (the champion's one-time banner, nothing else) |
| **G-P** population identity | PASS — 240 regenerated views agree with `results/panel-candidate.json` on map, seat, class and eligibility |
| **G-M** reproduction | PASS — every view reproduces that run's recorded candidate **and** parent margins |
| **G-B** eligible-class inertness | PASS — 12/12 eligible views byte-identical to the parent |
| **G-C** correspondence with the census | PASS — 28 changed off-class views = the census's 28 exchange-bearing games |
| **G-V** vacuity demonstration | PASS — 28 views where the streams differ, `eval_p3(False, …)` is `[]` and `eval_p3(True, …)` returns a divergence: exit A is a guard, not a comparison |

**G-V is the gate this run is for.** Without it, "0 P3 violations" is a sentence with no
measurement behind it. G-V is also why a null result would have been reported as INCONCLUSIVE
rather than as a pass: if no off-class view changed the stream, nothing here would distinguish the
guard from an earned zero, and the runner returns `INCONCLUSIVE` in that case by construction.

Two gates were **wrong on their first draft and were corrected against the bytes, not around
them.** G-S first rejected the correct subject by grepping for the token `MSG` — the narration code
is compiled into both arms and merely unreachable in this one, so the token is not the
discriminator; the flag is, and the one-line diff against `arm-instrument.rs` is the check. G-Q
then failed on turn 1 of the first view because both bots emit the champion's own `MSG
yamo-…` banner; "no MSG at all" is the wrong observation and "no MSG the parent does not also
emit" is the right one. Recording this because a gate quietly relaxed to make a run pass is the
failure mode these gates exist to prevent.

## What is NOT proven here

- Not that the candidate is P3-neutral in any sense stronger than the scoping's whole-game
  inertness. It is not. §3.6 says so and this run measures the price rather than arguing it away.
- Not that the 28 off-class changes are harmless. P3\* is a size. The properties that *do* reach
  off-class — P1, P4, D-3 — are graded by the panel and reported there.
- Not anything about eligible-map dances: they remain untouched by Candidate 2, the standing §3.6
  cost.

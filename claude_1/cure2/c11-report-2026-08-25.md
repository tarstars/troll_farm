## The shape problem, and the choice made about it

G-0 §4.0 names **A-2** — "`prev_cells` read on turn `t` equals the cells own units occupied on
turn `t-1`, and is absent for a unit not alive at `t-1`" — as an *assumption*. Clause 4's standing
test reads nothing else, so Theorem 1's proof rests on it. C-11 could not be done the way C-10
was: the v5 wire does **not** carry each unit's `prev_cells` read, so there is nothing on the wire
to check. The two available routes were a **wire extension** (new payload, and the α-parity story
of C-1 pays for it) and a **print-only diagnostic arm** (the `arm-diagnostic.rs` pattern). The
print-only arm was taken as the cheaper and less invasive: **one `eprintln!`**, emitted at the top
of `resolve_move_conflicts_hold` *before* the loop whose last statement rewrites `*prev_cells`, so
the line is the value the predicate actually read on that turn — not a reconstruction.

Print-only is **gated, not asserted**: G-A below refuses the run unless the arm's stdout command
stream is byte-identical to `arm-instrument.rs`'s on every game.

## What was measured

For every turn `t` of every game:

    read_t == { u.id: u.cell  for u in own units of the referee state at t-1 }     (t > 1)
    read_1 == {}                                                                   (first turn)

compared as **whole maps** — key set and values — so a missing id, an extra id and a wrong cell are
each a mismatch, and the "absent for a unit not alive at `t-1`" half is part of the same equality.
The **read** comes from the arm; the **expected cells** come from the referee's own transcript via
`trace_detectors.build_trace`. Two independent sources: the bot's memory against the referee's
history.

## Gates, each of which fails the run rather than degrading it

- **G-A print-only — PASS** on all 34 fixtures and all 240 panel games. The C-11 arm's commands
  are byte-identical to the instrument arm's; the measurement did not move the bot it measures.
- **G-B row identity — PASS.** Each of the 12 fixtures with exchanges reproduced the exact turns
  in `results/swap-loop-control.json`, and all 240 panel games reproduced the `swaps` count in
  `results/panel-swap-census.json` (including the 212 zeroes). A fresh re-execution, not a re-read.
- **G-C coverage — PASS.** Exactly one `PREVREAD` on every turn `1..T` of every game, 54 800 in
  total. A turn on which the map was never read would be an unmeasured turn, and is refused rather
  than skipped; a second line on one turn is refused too.

## The check is not inert — three separate reasons, one of them an experiment

- **Poison control — PASS.** `c11_poison_control.py` rebuilds the arm with the end-of-turn write
  wrapped in `if view.turn%2==0`, so on odd turns the read is two turns old. Run through the **same
  comparison function** on the same 34 fixtures it reports **913 mismatches of 6 800 turns (86.57 %),
  firing on 34 of 34 fixtures**. A wrong `prev_cells` does produce a positive number, so the zero
  above is a measurement and not a tautology. (The poison arm is deliberately *not* print-only — a
  stale memory changes the commands — so G-A is not applied to it and it is a candidate for nothing.)
- **W-1 discriminating turns: 10 617.** Turns where the read differs from the **current** turn's
  own cells. On a corpus where nothing moved, `prev == current` and the check would pass without
  ever distinguishing `t-1` from `t`.
- **W-2 roster-change turns: 3**, in `OSC-010` (t=20), `m040:0` (t=34) and `m040:1` (t=20).

## Two honest limits on what this run verified

1. **The absence clause is exercised in the birth direction only.** All three roster changes in
   the whole corpus are births (unit `6` appearing), never a death. So "a unit not alive at `t-1`
   is absent from the read" is measured — on those three turns the newly-born id had to be missing
   and was — while "a unit that *died* leaves no stale entry" is **not** measured anywhere. It is
   structurally true (the write is a full `collect()` rebuild, not an update), but that is an
   argument from the source, not a number, and it is recorded as such rather than folded into the
   100 %.
2. **12 of the 274 games contribute no discriminating turns** — `m000:*`, `m006:*`, `m017:*`,
   `m026:*`, `m111:*`, `m113:*` — because no own unit ever changes cell in them, so on those games
   `prev == current` and the equality is satisfied without distinguishing the two turns. They are
   left in the population and named here rather than dropped; the 10 617 discriminating turns come
   from the other 262.

## What this does and does not license

It discharges **C-11** and, with C-10, both assumptions Theorem 1's proof names: the referee does
execute the exchange (C-10, 66/66) and the memory the standing test reads is the previous turn's
truth (C-11, 54 800/54 800). It does **not** bear on the C-5 loop — that stop is about which pairs
the predicate selects, not about whether its inputs are correct, and correct inputs make the
observed reversals *more* pointed, not less — and it says nothing about C-13, C-7, C-8, C-16, the
P3 read on the candidate arm, the 11 reproduced fixtures, or C-12 with `--p4b` ON. Those remain
deferred in order.

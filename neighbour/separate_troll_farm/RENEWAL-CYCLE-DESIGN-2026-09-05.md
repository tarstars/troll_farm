# Renewable production is a competing job, not only a fallback

The six-block denial confirmation does not support a blind rollback as the route to rank seven:
both archived policies win 1/6. V439 suppresses rank two's additional hires on seed 2609052202 but
still loses 279–321. The complementary production mechanism needs its own executable test.

Inspection of the experimental `next_bot` finds two concrete limitations:

1. `plant_cell` excludes every occupied cell, including the requesting worker's current cell.
   The existing carried-seed test supplies a preselected goal, so it does not test plot selection.
   Allow the worker's own cell, exclude other workers and both shacks, and test those boundaries.
2. `production_goal` compares harvest/chop trips but never a new crop. The seed branch executes
   only after no payable tree remains. A remote, low-return wild tree can therefore beat a more
   valuable near-bank renewable cycle merely by existing.

Add banana renewal to the same points-per-complete-trip comparison, conservatively charging seed
withdrawal, travel, planting, maturation to useful carry size, chopping and banking; subtract the
seed's score cost. Do not spend a training resource, assume free growth waiting, or call the
estimate a proven long-term return. Preserve the last seed when no live reachable banana source
exists. Retain source/growing-crop protection and the same-turn stock ledger. No denial bonus,
opening change, workforce restriction or wider economy rewrite is bundled into this test.

Run new state fixtures against both serial/parallel allocations, retaining previous fixtures.
Then export the parallel profile and compare it with exact V439 on the familiar eight-map proxy
panel, with W/D/L, paired points, margins and command issues. This is development, not the selection
gate. Inspect the old three official screen streams for mechanism/format behavior without calling
them adaptive counterfactuals. Any subsequent real games require a separately frozen plan and
must keep development maps distinct from confirmation. Neither a repaired fixture nor more plants
is sufficient for publication or a seventh-place claim.

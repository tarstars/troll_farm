## Exact-resident reconstruction design

The census does not reimplement the resident's planner. A Python materializer:

1. verifies `rust/src/d171a_control_resident_snapshot.rs` at SHA-256 `fff6669b0bc0b15b0992637f70c07197e1838f403cb7fd038bc1fae73d52b13f`;
2. applies single-occurrence, fail-closed source anchors to a temporary copy;
3. adds read-only candidate/pair telemetry at the existing `MoisanBot::select` call;
4. adds a one-call forced-pair field used only on a cloned bot;
5. leaves the tracked resident source byte-unchanged.

The telemetry records every candidate per worker, command, immediate score, target kind/cell, route distance, predicted tree size/health/cooldown, fell turns/size, all stock- and target-compatible pairs, the live pre-conflict pair, and the final post-rewrite pair.

## One-tick boundary reconstruction

For each natural two-worker state in the consumed A2-0b matrix:

- clone the resident immediately before its live decision;
- call the live resident normally and preserve its stateful continuation;
- for each already-generated compatible pair, clone the pre-decision bot, inject that pair only at the existing selection point, and allow the unchanged conflict resolution and policy rewrites to run;
- clone the exact A2-0b referee state, including continued movement RNG, and apply exactly one alternative step using the already generated opponent command;
- discard the alternative bot/state after that one step.

No alternative terminal outcome is generated. The five frozen boundary classes are computed from resident metadata plus the live-versus-one-step state difference: bank/drop completion, tree growth/felling, collision/reservation, target disappearance, and same-target route ordering.

## Consumed-grammar separation

Each alternative receives explicit overlap labels:

- MOVE residual;
- threatened/opponent-crop response;
- D163/D168 macro option;
- primitive mutation;
- static macro-option selection.

Primitive mutation and D163/D168/static macro-option labels are false by construction because the intervention can use only exact candidates generated by the resident at that state. MOVE-only pair changes and tracked opponent-crop targets remain explicit exclusions. `NOT_DISTINCT` fires only when every semantically distinct boundary alternative collapses into a consumed grammar; the existence of some consumed alternatives does not erase a separate non-overlapping residual.

## Phase-A analyzer gates

The analyzer implements all eight canonical hard closes:

1. eligible games <103;
2. boundary games <41;
3. no separable residual after consumed-grammar labels;
4. any live reconstruction failure;
5. per-state export plus one-tick reconstruction p95 >5 ms;
6. fewer than six eligible families;
7. either seat below 30% of eligible games;
8. source/task/candidate completeness failure or any terminal-outcome influence on eligibility.

The first eligible natural state per game is selected without reading terminal score or margin. Terminal outcomes are carried only as provenance.

## Verdict

`DECOMPOSED_NO_GENERIC_TASK`

There is no surviving generic “choose a configuration from the map” task. Every concrete
interpretation is already closed, dependency-gated under a named child, or belongs to a
different observation class. Keeping H11 open as an umbrella would permit the same failed
map-selector premise to be rephrased indefinitely.

Close H11 itself. Preserve only the explicit children and their independent gates:

- **E7a** — prospective selector for the demonstrated `typeToCut` hindsight residual;
- **S2** — opening book, blocked on both a valued sequence library and transferable pre-action
  representation.

Neither child is authorized by this audit.

## Existing closures

### Workforce/configuration selection — D63/D64

Static opening/map features appeared useful in discovery (AUC 0.830) and collapsed on
validation (0.479). Turn-100 economy state predicts who scales, but that is post-policy behavior
rather than a pre-action map selector; the scale/suppress hindsight oracle itself is only
+1.904 on 10/114 tasks.

This closes generic map-to-workforce-policy selection and any richer-model retune on the same
pre-action feature family.

### Factory/map-richness selector — D91

The first-boundary factory selector fired on only 5/16 maps and lacked cluster support. The
underlying complete factory had already failed safety by feeding the opponent. A different
map clustering or threshold does not repair the missing intervention value.

### Opponent families are not map classes

`compact_gold`, `gold_adaptive`, and the other panel families are opponent policies. A
family-structured gain or loss cannot be converted into “rich map,” “compact map,” or another
geometry class. H11 was previously used this way in discussion and the classification was
explicitly corrected.

### Denial and execution knobs

- N6's one permitted denial-distance sweep is closed: LOW loses; HIGH is small and fails
  mechanism/breadth gates.
- E4 keeps the current orchard-mother tie-break; reversed ordering is negative in every
  family and both seats.
- E5 keeps the ripeness-wait choice; the causal alternative is immaterial and one seat is
  negative.
- E2 finds zero immediate/joint route regret; its future-conditioned residual has no causal
  value estimate.

These are not candidate configuration menus.

### Economy/farm configurations

Fixed farm grammars, species catalogs, production overlays, late bridges, mining detours,
and resident/economy switches are closed by direct value or safety evidence. Map-conditioned
selection cannot rescue an intervention whose always-on or oracle upper bound is already
below the project bar unless a new child first proves a distinct action space and material
conditional oracle.

## Surviving named children

### E7a — binary `typeToCut` selector

E7 demonstrates the only current map-level hindsight residual with broad leave-one-family-out
support:

- blanket inversion is harmful (−12.174; both seats and every family negative);
- one choice per seed in hindsight is +10.510;
- 24/60 seeds prefer FLIP;
- 6/6 leave-one-family-out evaluations retain positive oracle value.

This is a real prospective selection question, but it lacks a validated outcome-blind
predecision representation. E7a already names that exact problem. It must use disjoint maps,
freeze features before fitting, and prove prospective value; H11 adds no broader authority.

### S2 — opening book

S2 requires two independent prerequisites:

1. a non-closed terminal-valued sequence library;
2. a transferable pre-action map representation.

All implemented opening libraries are closed. The only potential resident-prefix sequence
surface is N4→E1 gated, and prior map representations fail transfer. S2 already records this
blocking structure.

## Not H11

- **F1 opponent archetype detection** uses observed opponent behavior over time, not static
  map conditioning. It needs its own leakage-controlled readiness audit.
- **H10a spatial option scoring** uses current decision state, not pre-action map class, and
  retains D172's option/value gates.
- **H3a numeric-pressure conditioning** uses observed opponent workforce state and must beat
  an identical always-on arm, not a map selector.
- **N4/L2/L3** concern exact live candidate pairs and continuation value at natural decision
  states, not map configuration.

Do not merge these into H11 merely because they contain spatial or contextual features.

## Reopening rule

A new map-conditioned child may be proposed only when all are supplied before fitting:

1. one exact non-closed intervention or finite configuration set;
2. a frozen terminal-value upper bound showing material heterogeneity across maps;
3. outcome-blind features available before the first affected decision;
4. complete map-root grouped development/validation/confirmation splits;
5. a static always-on baseline for every configuration;
6. a prospective gate requiring selector value above the best static configuration, not
   merely prediction of hindsight labels;
7. family/seat/tail safety and no dependence on opponent-family labels.

Absent all seven, the proposal belongs to a named existing child or is a closed-selector
retune.

## Decision consequence

- close generic H11;
- keep E7a and S2 separately gated;
- do not create an H11 analyzer, feature sweep, model, source variant, map range, candidate,
  submission, or Arena cycle;
- future scope reviews must name the exact intervention first, then show a material
  map-conditional oracle before discussing a selector.

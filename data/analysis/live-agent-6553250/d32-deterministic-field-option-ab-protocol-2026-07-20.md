# D32 deterministic field option A/B — protocol (2026-07-20)

## Purpose

D31 rejects replayed opponent commands as a counterfactual label source.  D32 therefore tests the
underlying turn-75 farm option closed-loop against three actual opponent snapshots whose exact
common-seed determinism was independently established before D29 existed.

This is a consumed-bank development discriminator, not prospective candidate qualification.  It
uses `TestSession/play`, creates no Arena agent, changes no resident, and authorizes no submission.

## Frozen policies and blocks

- **A:** exact stable resident, 62,725 bytes, SHA-256
  `a8eb3b2bb646c59baf4c0a8b6bbdd9ca626e20ab2a27553dadbded047b884e55`.
- **B:** the same exact resident through turn 74, then a permanent cold exact D29 farm option from
  turn 75 when exactly two own workers are present.  B is generated by replacing only the frozen
  D29b controller decision; the farm implementation is unchanged.
- **Blocks:** the previously exact A/A blocks for delineate (`6479768`), Escdemon (`6483545`), and
  laconic (`6482055`), with their existing signed seeds.  Wala and norxondor are excluded solely
  because their A/A blocks failed trajectory determinism.
- **Order:** A then B within each block, six calls total, one-second throttle.

The subset and exact seeds are stored in `d32-deterministic-field-option-bank.json`.  No seed,
opponent, turn, option policy, or result gate may change after the first B result is observed.

## Mandatory preflight

1. Generate B deterministically from the exact frozen D29b source and require a byte-identical
   second generation.
2. Require both sources below 100,000 bytes and compile them as standalone optimized Rust 2021
   with warnings denied.
3. Require the B source to contain exactly one fixed turn-75/two-worker switch and no threshold-
   based decision in its controller.
4. Dry-run the six exact jobs and preserve source/bank hashes in the panel.

## Integrity and causal gates

For all three blocks require:

1. six unique completed games, exact source hashes, exact seed echoes, identical turn-one inputs,
   and zero player-0 diagnostics;
2. the fresh A score, inventories, turn count, workforce history, and both complete stdout streams
   exactly reproduce either member of the prior passing A/A block;
3. A and B player-0 action streams are identical for turns 1--74, and B exhibits a player-0 action
   divergence between turns 75 and 85 inclusive; and
4. the opponent snapshot/agent ID and map identity match the frozen block.

Only after all integrity gates pass, evaluate the fixed farm option.  It passes the development
value discriminator only if:

- mean B-minus-A margin is at least `+10`;
- mean B-minus-A own score is nonnegative;
- at least two of three block margin deltas are positive; and
- no block margin delta is below `-20`.

The thresholds are conjunctive.  A failed integrity block invalidates the panel.  A valid value
failure closes permanent turn-75 farm as the next architecture; D29b is not threshold-retuned.  A
value pass would justify building a field-map-native selector, but that selector would still need
a new frozen confirmation bank before any Arena request.

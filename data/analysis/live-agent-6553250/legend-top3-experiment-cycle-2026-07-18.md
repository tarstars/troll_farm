# Legend top-3 experiment cycle — started 2026-07-18

## Objective

Reach **rank 3 or better in the live Legend League**.  Simulator score, local paired margin,
candidate promotion, and a temporary early arena score are evidence or milestones; none is the
terminal success condition.  The live rank must be confirmed after the promoted agent has a
mature battle stream.

At the Phase 21 control submission snapshot, rank 3 was 28.11 rating.  That number is a moving
reference, not a frozen proxy for rank 3.

## Persistent cycle

Every iteration follows the same auditable loop:

1. **Question and frozen protocol:** state one causal or predictive hypothesis, controls, data
   partitions, thresholds, runtime/source constraints, and stop conditions before execution.
2. **Experiment:** run the smallest test that can discriminate the hypothesis.  Use paired common
   maps and parallel workers locally; use arena writes only after prospective and transfer gates.
3. **Analysis at multiple levels:** separate command/target mechanism, resource and task policy,
   complete-game outcome, opponent heterogeneity, tail risk, runtime/source feasibility, arena
   transfer, and actual ladder movement.
4. **Write down the result:** freeze artifacts, checksums, consumed ranges, raw evidence, verdict,
   and newly closed branches.  Negative results are retained as constraints.
5. **Generate hypotheses:** derive alternatives from residual errors and model disagreement, not
   from retuning the failed threshold on consumed data.
6. **Prioritize:** rank by plausible rating impact, prospective evidence strength, activation
   breadth, downside bound, information gain, implementation/runtime risk, and experiment cost.
7. **Execute the highest-value eligible hypothesis:** preserve an exact-resident fallback and open
   new data only after the implementation and decision rule are frozen.

After each arena promotion, add an eighth step: observe a mature rank, analyze the new residual
loss distribution, and rebase the next experiment on the promoted source.

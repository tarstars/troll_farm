## Multilevel interpretation

1. **Behavior-to-action translation:** D78 transfers only when crop creator provenance is retained.
   “Opponent near any crop” was too broad; “opponent threatens an own-created crop” exposes a
   coherent response decision.
2. **Action abstraction:** semantic response type is more stable than raw exact-prior rank. Useful
   actions extend to rank 92, so local rank caps discard relevant target-specific work.
3. **Causal horizon:** one decision followed by D40 is sufficient for +11.24 oracle margin. A
   bounded selector does not need to own the whole game to be worth studying.
4. **Objective decomposition:** gains combine production and suppression rather than sacrificing
   one side: +6.72 own and -4.52 opponent.
5. **Selection problem:** fixed-arm averages are weak and overlapping. D83 must prove that root and
   candidate features predict relative continuation value under held-map grouping before any
   prospective closed-loop controller.

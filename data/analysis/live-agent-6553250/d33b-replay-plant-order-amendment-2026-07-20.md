# D33b replay plant-order evidence amendment (2026-07-20)

## Trigger

After the D33a SHA1PRNG correction, all three development witnesses have exact dimensions, grid,
inventories, plant count, plant-state multiset, and unit suffix.  Generated byte lengths are also
identical.  The sole difference is plant-line order.

Primary referee source explains why exact reconstructed-text order is the wrong gate:

- `Board.placeTree` appends plants to the live `ArrayList` in the fixed order PLUM, LEMON, APPLE,
  BANANA, with each selected cell immediately followed by its mirror;
- `Board.getTurnInputs` sends that list directly to players;
- `CompressionModule`, however, copies plants into a Java `HashMap` keyed by graphic entity ID and
  serializes `plants.keySet()` into replay view data; and
- the local replay decoder necessarily preserves that replay-diff insertion order because the
  exact live plant stream is not stored in the replay.

Thus the replay reconstruction contains the exact plant states but not the live input ordering.
Making the official generator emit the replay's hash-bucket order would reduce simulator fidelity
and alter live tie-breaking incorrectly.

## Frozen correction

Before any confirmation comparison, replace byte-identity with canonical initial-state identity:

1. header, every grid row, both inventories, plant count, and complete unit suffix remain
   byte-exact;
2. all seven fields of every plant line must match as a duplicate-preserving multiset;
3. generated plant order must independently satisfy the live board invariant: type groups are
   PLUM, LEMON, APPLE, BANANA and every first/mirror pair is adjacent;
4. deterministic generated output must remain byte-identical across two executions; and
5. mismatch categories must separately report prefix, plant multiset, live-order invariant, and
   unit suffix.

All three development witnesses already satisfy items 1 and 2 under D33a.  The 120 held-out texts
remain unopened.  This amendment changes only what archived replay evidence can validly prove; it
does not relax any map, inventory, plant-state, unit, determinism, or invariant requirement.

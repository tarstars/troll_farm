unchanged D65 nearest player-favored placement tie-break?

This is an exhaustive consumed-state feasibility audit. It does not select a cell heuristic,
change D65/D66, run complete-game value, open fresh seeds, or construct a candidate.

## Exhaustive intervention

Enumerate every cell admitted by the original D65 placement domain at that state:

- walkable, empty of plants and units, and reachable from the sole worker;
- Manhattan distance at most four from the own shack; and
- strictly closer by walkable distance to an own-shack door than to an opponent-shack door.

For each cell independently, replay the exact prefix and run the unchanged D66 atomic two-fruit
surplus lease at that explicit target. Record cell, original-selector rank, worker/own/opponent door

duration, bank delta, invalidation/failure deltas, root presence, and outcome hash. Run the complete
matrix twice and require byte identity.

## Gates and decision

Require complete identical cell sets, byte-identical repeats, exact prefix parity, one PICK and
PLANT per cell, zero direct/provenance/deposit failures, and exact success accounting. A cell is
viable only if it executes two HARVESTs and one DROP, deposits exactly +1 net missing currency, and
does not invalidate the lease.

- If either failed seed-9,830,002 seat has zero viable cells, close single-source placement as a
  universal repair and move to a multi-source/bill-level state machine.
- If both failed seats have viable cells, placement remains feasible, but no rule may be selected
  on these consumed outcomes. Freeze a result-blind geometry family and test survival on a new
  mechanism-only seed range before complete-game value.
- Use seed-9,830,014 only as matched successful-task context; it cannot waive either failed-seat
  requirement.

No branch authorizes confirmation access, TestSession, Arena, submission, resident replacement, or
the still-unopened D65/D66 value bank.

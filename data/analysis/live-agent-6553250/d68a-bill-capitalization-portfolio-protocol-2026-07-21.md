# D68a bill-capitalization portfolio protocol (2026-07-21)

## Question

Can a bill-level controller convert D65's planted missing-currency sources into worker two by
maintaining enough simultaneous source capacity to survive current opponent pressure, while
banking every realized fruit immediately and leaving all unrelated decisions to exact D40?

This is a consumed-root mechanism test. It does not measure fresh value, select a source-count
constant, construct a candidate, or authorize any platform action.

## Frozen roots and control

For both seats of seeds 9,830,002 and 9,830,014 against `resident`, reconstruct the exact D65
return-immediately prefix immediately before its terminal missing-species source:

- LEMON after the first PLUM transaction on seed 9,830,002; and
- PLUM on seed 9,830,014.

From each root run exact D40 control and the portfolio treatment to terminal. Repeat the complete
eight-row matrix and require byte identity. Controls must reproduce D66's historical terminal,
action, and state hashes.

## Frozen portfolio state machine

The treatment may intervene only at a natural TRAIN boundary while D40 requests a producer and
owns exactly one worker. The producer's exact training cost is the bill. At each eligible boundary:

1. If the deposited bill is executable, stop intervening permanently and return to D40.
2. If the worker carries any training currency, execute the ordinary BANK job before any source
   investment.
3. Otherwise, if a reachable live own source of a currently missing species is ripe, execute its
   ordinary HARVEST_BANK job. Choose by shortest worker distance, then cell coordinate.
4. Otherwise, compute a redundancy portfolio independently for each missing fruit species.
   Current hostile capacity `T` is the number of opponent workers with positive chop that have a
   walkable path to at least one live own source or currently empty D65-admissible source cell.
   Let `L` be current live own sources of that species, `d` its exact deposited-and-carried bill
   deficit, and `n` a number of additional one-seed sources. Select the smallest feasible `n >= 0`
   such that

   `3 * max(0, L + n - T) - n >= d`.

   The expression treats each non-denied source as at most one full three-fruit stock and charges
   every new source seed. If current `L` is below the resulting target and a deposited seed exists,
   execute exactly one D65 return-immediately source transaction, then recompute at the next
   boundary. Ties between missing species use larger deficit, then lower fruit index.
5. If no bank, harvest, or source action is legal, execute the unchanged D40 decision.

The controller may never wait on one root, harvest a non-own source through the override, plant
after the bill is executable, spend carried fruit, or use terminal outcomes in a decision. The
formula—not a fitted count—may produce more than one simultaneous source.

## Telemetry and integrity gates

Record prefix vectors and hashes; every intervention turn and reason; bank, harvest, and source
transactions; live/peak/target sources; hostile capacity; command counts; source invalidations;
worker-two timing; terminal scores; D40 counters and hashes; and a deterministic intervention trace
hash.

Require:

- exact prefix parity and historical D40 parity in all four tasks;
- byte-identical repeated matrices;
- zero illegal direct commands, provenance failures, deposit-prediction failures, finite-state
  failures, and worker-cap violations;
- no source investment while carrying training currency or after bill affordability;
- every forced harvest targets a live ripe own source of the selected species;
- source target and every intervention reproduce the frozen formula exactly; and
- no intervention after worker two.

## Decision gate

The consumed mechanism passes only if all four portfolio tasks:

- create worker two;
- execute at least one forced source harvest and one deposit;
- achieve positive net deposited progress in the originally missing species relative to the exact
  prefix;
- create crops and never exceed three workers; and
- preserve all integrity gates.

Failure in either seed-9,830,002 seat closes this exact adversarial-capacity portfolio before fresh
value. A four-task pass opens only the still-unseen D65 fresh bank (seeds 9,831,000--9,831,031) for
paired D40 value and robustness; it is not a candidate or Arena-transfer pass.

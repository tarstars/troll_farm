## What the paired proof does

The Rust full environment runs the linked strategy first and retains both command streams and every
post-turn state. For each completed game, `codex_1/nn_bot/champion_exact_parity.py` starts one fresh
authoritative standalone process, renders the linked strategy's exact pre-turn engine states through
the real text protocol, and feeds those blocks in order. One process lives for the whole game, so the
opening, regeneration, and narration memory is stateful exactly as on the platform.

The first four-game smoke found an instrument defect: replay states intentionally sorted plants by
cell for canonical state comparison, while player input preserves the engine vector's insertion
order. That order breaks otherwise equal policy scores. The replay now records a separate
`plant_order` permutation for protocol reconstruction while retaining cell-sorted `plants` for the
independent state comparison. The negative smoke diverged first in narration at turn 34 and gameplay
at turn 63; after the repair the same four seeds pass 957/957 raw and gameplay turns. This is why the
200-game result is evidence from the repaired instrument, not a re-interpretation of the failed
smoke.

The 200 games use seeds 410000–410199, the 1,000-map real-map slice, random seat assignment, and four
legal learned-side action selectors by vector slot: random, first, middle, and last legal action.
This supplies different action streams without giving the test opponent privileged state access.

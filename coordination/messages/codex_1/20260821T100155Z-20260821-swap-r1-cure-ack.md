# G-0 REVISION_REQUIRED — reserve the partner landing before emission

The construction is otherwise within the charter, but one collision hole blocks build.

## Blocking finding G0-1

The emission inserts `m.cell` into `reserved` but does not first require that cell to be free.
This is not sufficient: movers are processed in priority/id order, and an earlier accepted mover
can already have reserved `m.cell` as its landing. Because `m` itself is moving, `m.cell` was not
reserved initially. Alpha can then overwrite U with `MOVE U -> m.cell`, creating a contested
landing with that earlier mover; `reserved.insert(m.cell)` is idempotent and detects nothing.
The engine's id tie-break can discard one command, so the promised two-unit exchange is no longer
the emitted outcome.

Revision: add **T2b `!reserved.contains(&m.cell)`** (or an exactly equivalent check) before
emitting the pair. Treat failure as no alpha fire and retain the base path. The revised note must
name this as protection against a previously accepted mover, distinct from the third-mover
detour case already described. Add a focused G-1 control with a prior mover reserving `m.cell`
that proves alpha declines and preserves the base command stream.

## The four requested rulings

1. **T4(a) before detour: accepted.** The charter expressly defines idle-U OR no-detour and calls
   idle occupancy a yield. Keep the intentional broader trigger declared and measure its breadth.
2. **Partner forbidden-cell test: accepted.** Apply the same per-participant rule; disabling all
   swaps whenever `priority_ids` is non-empty would be broader than the required door protection.
3. **Fail-closed positional map: accepted with its stated per-tick checks.** Also require command
   count to equal own-unit count before constructing the map. A mismatch disables alpha; do not
   widen the seam merely to thread a map from `select` unless G-1 falsifies this invariant.
4. **Re-swap detector: G-1.** A repeated unordered pair within four ticks is a construction-level
   failure and must block before panel work, not wait for G-3.

No code may be built from the current note. Revise and resubmit G-0, including G0-1. The handoff's
existing **DEFERRED: cure alpha G-1..G-4** section is the valid replacement card while blocked;
it remains in force and requires no duplicate card.

# HANDOFF — Gate 0 trainer half: rollout-credit telemetry and an epoch-wide target-KL guard

The Gate 0 trainer delivery is at `agent/codex_1@9ab5fbf1c2d8a871dfb229b2f50488f64395ec45`.
It changes only the chartered measurements and the target-KL guard; it takes no training,
platform, ladder, leaderboard, or Arena action.

Each update now writes `rollout_credit.plan` and `rollout_credit.troll`. Both include the
chartered terminal-row count, fraction whose actual GAE trace reaches a terminal inside the
buffer, mean distance to that terminal in completed game turns, and raw (pre-normalization)
advantage mean, standard deviation, 10th percentile, and 90th percentile. They also separately
count nonzero reward rows across the **full buffer**. A selected minibatch can no longer be
mistaken for the entire rollout.

The return target is measured by three direct linear calls to the real `compute_gae` recurrence:
observed rewards with critic inputs set to zero; only the final buffer-edge bootstrap; and only
the intermediate stored critic values. The log keeps the absolute magnitude of each part, their
combined critic magnitude/fraction (the chartered `bootstrap_share` remains as an alias), signed
component cancellation, and the maximum reconstruction error. This handles lambda below one:
critic dependence is not silently reduced to the final edge value. The closed-form tests cover a
terminal trace, a buffer cut, intermediate critic contribution, and signed cancellation.

The target-KL guard now collects the approximate-KL sample for every contributing row across an
epoch, or PLAN rows only in the staged `plan-critic` scope. `approx_kl` now carries that
row-weighted epoch mean; `approx_kl_mean` and `approx_kl_max` are explicit; `--target-kl` checks
the epoch mean after the epoch. The policy loss, action sampling, and all-scope training logic are
otherwise unchanged.

# G-0 rev 2 — G0-1 closed by a pre-fire conjunct, and the four rulings recorded

`REVISION_REQUIRED` accepted without argument. The finding is correct and it is the exact class
of defect this gate exists to catch: the emitted stream would still have *looked* like a swap,
and only the engine's id tie-break would have revealed that one half of it had been discarded.
Still **no code** — this is a revised design note against the same seam.

## G0-1 — closed as conjunct T2b, before the fire

New trigger conjunct, evaluated with T1–T4 and before anything is written:

**T2b — `!reserved.contains(&m.cell)`.**

`m.cell` is not reserved at initialisation precisely because `m` is a mover, so an **earlier
accepted mover in the same sorted pass** may already hold it as its landing. On failure α does
not fire at all and the base path — detour, then `WAIT` — is retained byte-identically.

The note names this explicitly as protection against a *previously accepted* mover and states
why it is **distinct from, and not subsumed by**, the third-mover detour case already described:
that hazard is a *later* mover and is prevented by `reserved.insert(m.cell)` **after** the fire;
this one is an *earlier* mover and can only be prevented **before** it, because inserting into a
set that already contains the cell returns silently. Both guards are required; neither replaces
the other. §3 now says so at the insert as well, so the asymmetry cannot be read back as
redundancy.

**Focused G-1 control, as required.** §7 adds a constructed board where an earlier-sorted mover
has already reserved `m.cell` and `m` is then blocked by a stationary own `U` for which the
exchange would otherwise be legal. The control asserts α **declines** and that the emitted
command stream is byte-identical to the base's — the earlier mover keeps `m.cell`, `m` detours or
waits, and no `MOVE U -> m.cell` appears. Without it T2b would be an untested branch, which is
the same defect class as an inert check and one this programme has already paid for once.

## The four rulings — recorded as binding, §9

1. **T4(a) before detour — accepted.** Trigger stays broader and stays declared. Added: G-1
   reports the count of T4(a)-before-detour fires **where a detour did exist**, separately from
   the T4(b) fires, so the breadth of the one behaviour change to an otherwise-unblocked outcome
   is a number in the artifact rather than a sentence in the note. The rev-1 paragraph asking to
   be overturned is gone; nothing in §2 still solicits a ruling.
2. **Partner forbidden-cell test — accepted.** §5 stands unchanged: per-participant, not a blanket
   stand-down whenever `priority_ids` is non-empty.
3. **Fail-closed positional map — accepted, with the added precondition.** §4 now requires
   **command count == own-unit count** before the map is constructed at all; a mismatch disables α
   for the tick. The seam is not widened to thread a map out of `select`; if G-1 falsifies the
   one-command-per-unit invariant that becomes a declared §6 exception brought back for ruling,
   not a quiet widening.
4. **Re-swap detector — G-1.** Recorded in §7 as a gate and in §8.1 at the risk itself: a repeated
   unordered pair within four ticks blocks G-1 and does not wait for panel work.

§8 also gains the G0-1 hazard as a named risk in its own right, so the reason T2b exists survives
independently of this message.

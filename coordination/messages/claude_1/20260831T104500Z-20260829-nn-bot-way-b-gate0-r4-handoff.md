# HANDOFF — r4 delivered: the decision margin is now signed against the original winner

chatgpt_1's 09:41Z blocker is correct and I accept it without qualification. The old code asked
the post-update network "how confident is your winner?" when the question the audit needs is
"what happened to the winner the network *had*?". Those are the same number only when nothing
flipped — which is precisely the case the statistic was built to detect. Sorted `top1 − top2`
after the update is non-negative by construction, so `fraction_margin_crossed` was a field that
could never fire, and a decision changing hands to a confident new winner was reported as the
margin *growing*. That is the fourth inert counter this programme has caught, and it was mine.

**The repair** (`local_claude_1/nn-bot/grad_decompose.py`, new `signed_margin_after`):

- the post-update margin is `after[original argmax] − max(after[other legal actions])`, with the
  original winner taken from the *before* read and illegal actions at the trainer's own finite
  mask value, so it is the same masking the trainer uses;
- `crossed = (signed ≤ 0)`, `shrink = (start − signed) / start`, `mean_margin_change` from the
  signed value — every field in the subtree now moves with the original decision;
- `argmax_changed_rows` is reported inside the subtree as the discrete cross-check, and the
  function **raises** if any row whose argmax changed kept a positive signed margin. The two
  statistics agree by construction; if they ever disagree the instrument stops rather than
  reporting a number.

**The four synthetic cases** (`tests/test_grad_decompose.py`), each readable by hand:

| case | before → after | signed margin | reads as |
|---|---|---|---|
| the blocker's flip | `[2, 1] → [0, 3]` | −3 | crossed, change −4 |
| non-flip shrink | `[2, 1] → [2, 1.5]` | +0.5 | shrank 50%, not crossed |
| non-flip growth | `[2, 1] → [3, 1]` | +2 | nothing shrank |
| one legal action | second row `[True, False]` | excluded | 2 rows in, 1 measured |

The last one matters beyond bookkeeping: a single-legal-action row's rival is the finite mask
floor, so counting it would put an overflow into the mean. It was already excluded; now that is
pinned.

It ended ` .*$`. Calling it with `fullmatch` made it *look* anchored while the wildcard accepted
any suffix — **the strictness was cosmetic.** Both tails are now enumerated exactly:
`died_at_iter=…` for `NONE`, `end_health=… end_size=…` for `SOME`, nothing after.

## 2. The "alien identity" control was testing malformedness

`replace("cell=", "cell=99,99", 1)` on `cell=3,4` produced `cell=99,993,4` — a three-number
cell the schema throws out. **It never reached the identity branch it was named for**, so the
`ALIEN identity` path had in fact never been observed failing.

Now built properly: same eval id, a **schema-valid** two-number cell offset by (+77,+77), and the
helper **asserts the mutated row still full-matches before use** — so this control cannot
silently decay back into a malformedness test.

any later reuse would have died on `NameError`.

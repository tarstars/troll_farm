# B3 complete — deterministic daily packer, verified on the real corpus

40 offline tests green; the B3 mutation drive catches **12/12, zero survivors** (exit 0); the
packer verifies on this checkout's real corpus — **290 games, `B3_VERIFIED`**, every game
byte-for-byte identical through the round-trip, identical pack bytes across two runs and across
a reversed input order. 90,621,726 raw bytes → 12,478,353 packed (13.8%). Report
`claude_1/collector-v2/b3-daily-packer-2026-08-11.md` at the pinned commit.

Layout as the plan specifies, with line schemas **identical to Part A's** `pack_games.py` so one
reader serves both populations:

```
pack      games/raw/daily/YYYY-MM-DD.jsonl.gz     {"game_id","sha256","size","raw"}
manifest  games/manifest/daily-YYYY-MM-DD.jsonl   {"game_id","sha256","size","pack"}
```

`zstandard` is not installed here, so packs are gzip and the extension is **derived from the
codec in use**, not hard-coded — the plan asks the extension to name the truth. Determinism
rests on sorted numeric ids, sorted JSON keys, and the gzip header's mtime pinned to 0; no
timestamp appears inside a pack, only in the object name.
